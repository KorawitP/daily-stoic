> **366 วันแห่งปัญญาและการใช้ชีวิต — ปรัชญาสโตอิกสำหรับทุกวัน**  
> หนังสือต้นฉบับ: *The Daily Stoic* โดย Ryan Holiday & Stephen Hanselman  
> ฉบับแปลไทยสมบูรณ์ 366 วัน จัดทำเพื่อการอ่านส่วนบุคคลและการฝึกฝนจิตใจ

## จุดเด่นและการแก้ปัญหาเชิงพฤติกรรม (Key Highlights)

1. **ปลดล็อก "แรงต้านเรื่องวันที่" (Zero-Guilt Journey Mode):**
   - ในหนังสือเล่มจริงผูกติดกับวันที่ตามปฏิทินสากล (เช่น 1 มกราคม) ทำให้เมื่อเริ่มอ่านกลางปี หรือวันที่ไม่ตรงจริง เกิดความรู้สึกผิดหรือแรงต้าน
   - โหมดหลักของแอปจะแสดงผลเป็น **"ก้าวที่ 1 ถึง 366" (Day Step)** ไม่ผูกติดกับปฏิทิน เริ่มอ่านวันไหน ก็เริ่มที่ก้าวที่ 1 เสมอ (มีปุ่มสลับดูวันที่ปฏิทินเดิมได้ตามต้องการ)

2. **ระบบเช็คอินและสถิติต่อเนื่อง (Daily Check-in & Habit Tracker):**
   - ปุ่มติ๊ก **"อ่านแล้ววันนี้"** พร้อมแอนิเมชัน Confetti ฉลองความสำเร็จ
   - คำนวณ **Streak** วันที่อ่านติดต่อกันอัตโนมัติ (คำนวณตามวันที่จริง ไม่นับค้างหากขาดช่วงเกิน 1 วัน)
   - ปุ่มส่งเสริม **"ก้าวต่อไป →"** เพื่อความลื่นไหลในการอ่าน

3. **ระบบอ่านออกเสียงอัตโนมัติ (Web Speech Audio Reader):**
   - ฟังเสียงอ่านบทเรียนประจำวัน (เสียงสังเคราะห์ภาษาไทย) ผ่าน Web Speech API ทำงานแบบออฟไลน์ 100% ไม่ต้องใช้อินเทอร์เน็ต

4. **สมุดบันทึกสะท้อนคิดยามค่ำ (Evening Journal & Reflections):**
   - กล่องพิมพ์บันทึกสั้นๆ ท้ายบทเรียน บันทึกสิ่งที่ได้เรียนรู้และนำไปปรับใช้ในชีวิตจริง
   - บันทึกอัตโนมัติขณะพิมพ์ (Auto-save) พร้อมระบบ Flush ข้อมูลขณะเปลี่ยนหน้า ป้องกันข้อความสูญหาย 100%
   - หน้าต่าง **"สมุดบันทึกสะท้อนคิด" (Reflections Modal)** สำหรับค้นหาตามคำค้นหา/นักปราชญ์/เลขก้าว พร้อมระบบ **แก้ไขบันทึกได้โดยตรง (Inline Editing)**
   - นับจำนวนคำและตัวอักษรภาษาไทยอย่างแม่นยำด้วย `Intl.Segmenter` และ **ส่งออกเป็นไฟล์ Markdown (.md)** ไปยัง Obsidian, Notion, Logseq หรือ Day One

5. **ระบบสำรองและกู้คืนข้อมูล (Backup & Restore):**
   - ส่งออกข้อมูลความก้าวหน้า รายการโปรด และบันทึกทั้งหมดเป็นไฟล์ `.json`
   - นำเข้าข้อมูลสำรองพร้อมระบบตรวจสอบและทำความสะอาดข้อมูล (Data Sanitization) เพื่อป้องกันข้อมูลเสียหาย และซิงค์หน้าก้าวปัจจุบันให้อัตโนมัติ
   - ปุ่มรีเซ็ตข้อมูลทั้งหมดอย่างปลอดภัย พร้อมระบบแจ้งเตือนยืนยัน

6. **กำแพง 366 ก้อนอิฐแห่งปัญญา (Brick-by-Brick Grid):**
   - อิงคำสอนวันที่ 8 มิถุนายน (*"ก่อร่างสร้างชีวิตทีละการกระทำ ดั่งการก่ออิฐทีละก้อน"*)
   - แสดงผลเป็นตาราง 366 ช่อง แยกตาม 3 ภาค (การรับรู้ / การกระทำ / เจตจำนง) พร้อมตัวกรอง "ยังไม่อ่าน" และปุ่มกระโดดสู่ "จุดเดินทางปัจจุบัน"

7. **ยาใจสโตอิกตามสภาวะอารมณ์ (Stoic First-Aid / Topic Mode):**
   - 8 หมวดหมู่ปฐมพยาบาลทางจิตใจ พร้อมตัวกรองแยกตามนักปราชญ์ (Marcus Aurelius, Epictetus, Seneca):
     1. 😡 **ความโกรธ & ความขัดแย้ง** (Anger & Conflict)
     2. 😰 **ความวิตกกังวล & ความกลัว** (Anxiety & Fear)
     3. 🛋️ **การผัดวันประกันพรุ่ง & การลงมือทำ** (Procrastination & Action)
     4. 💸 **อัตตา & เงินทองชื่อเสียง** (Ego, Wealth & Status)
     5. 💔 **ความสูญเสีย & ความโศกเศร้า** (Grief & Loss)
     6. 🧭 **การควบคุม & ความแจ่มชัด** (Control & Clarity)
     7. 🎯 **หน้าที่ & คุณธรรม** (Duty & Purpose)
     8. 💀 **มรณานุสติ & คุณค่าของเวลา** (Mortality & Time)

8. **ปฏิทินสโตอิก 12 เดือน (Calendar Mode):**
   - แบ่งตามโครงสร้างดั้งเดิม 12 เดือน 3 วินัย พร้อมปุ่ม **"อ่านของวันนี้"** เพื่อกระโดดไปยังวันที่ตามปฏิทินจริงได้ทันที

9. **ระบบค้นหาแบบ Multi-Term Full-Text (Instant Search):**
   - ค้นหาได้หลายคำพร้อมกัน (เช่น "seneca ความตาย", "marcus อารมณ์", "ก้าว 45", "day 120", เนื้อหาบทความ, คำคม)
   - ตัวกรองแยกตามนักปราชญ์และภาคปรัชญา

10. **การ์ดคำคม & ส่งออกรูปภาพความละเอียดสูง (Canvas PNG Quote Card):**
    - สร้างรูปการ์ดคำคมสโตอิกอัตโนมัติความละเอียดสูง (1080x1080) ผ่าน HTML5 Canvas แบบออฟไลน์ 100% บันทึกเป็นไฟล์ `.png` สำหรับแชร์ลงโซเชียลมีเดีย
    - รองรับ Native Web Share API และการคัดลอกข้อความลงคลิปบอร์ด

11. **คลังปัญญา อภิธานศัพท์ และบทนำฉบับเต็ม (Glossary & Full Intro):**
    - บรรจุ **บทนำฉบับแปลไทยเต็มรูปเล่ม** จากผู้เขียน Ryan Holiday & Stephen Hanselman
    - อภิธานศัพท์ภาษากรีกโบราณ (*Amor Fati*, *Memento Mori*, *Ataraxia*, *Prohairesis*, *Logos*, *Sympatheia*, etc.)

12. **3 ธีมอ่านสบายตา และปรับขนาดตัวอักษร:**
    - 📜 **Parchment (กระดาษโบราณ):** โทนสีครีมน้ำตาลอบอุ่น นุ่มนวลต่อสายตา
    - 🌙 **Dark Slate (มืดสโตอิก):** โทนสีเทาเข้ม เหมาะกับการอ่านยามค่ำคืน
    - ☀️ **Light (สว่าง):** โทนสีขาวสะอาดตา เรียบง่ายทันสมัย
    - ปรับขนาดตัวอักษรได้ 4 ระดับ (SM / MD / LG / XL)

13. **ทางลัดคีย์บอร์ด (Keyboard Shortcuts):**
    - `Ctrl+K` หรือ `Cmd+K` หรือ `/`: เปิดหน้าต่างค้นหาบทเรียนทันที
    - `Esc`: ปิดหน้าต่าง Modal ทุกประเภท
    - `←` หรือ `H`: วันก่อนหน้า
    - `→` หรือ `L`: วันถัดไป
    - `C`: เช็คอินอ่านแล้ว (ไม่ชนกับ Ctrl+C คัดลอกข้อความ)
    - `F`: บุ๊กมาร์กรายการโปรด (ไม่ชนกับ Ctrl+F ค้นหาในเบราว์เซอร์)
    - `R`: สุ่มบทเรียนสโตอิก (ไม่ชนกับ Ctrl+R รีเฟรชหน้า)

14. **ทำงานแบบออฟไลน์ 100% & PWA (Installable):**
    - โหลดครั้งเดียวเปิดอ่านได้ตลอดแม้ไม่มีอินเทอร์เน็ต
    - สามารถกด "Add to Home Screen" หรือ "Install App" ติดตั้งลงบนโทรศัพท์มือถือ (iOS/Android) และคอมพิวเตอร์ได้เหมือน Native App

## วิธีเปิดใช้งาน (How to Run)

### วิธีที่ 1: ดับเบิลคลิกไฟล์เดียว (ง่ายที่สุดบน Windows)
- ไปที่โฟลเดอร์ `C:\Users\kokok\Downloads\book`
- ดับเบิลคลิกไฟล์ **`start_stoic_reader.bat`**
- ระบบจะเปิดเบราว์เซอร์ไปยัง `http://localhost:5173` ให้โดยอัตโนมัติ

### วิธีที่ 2: รันผ่าน Terminal / PowerShell
```powershell
cd C:\Users\kokok\Downloads\book\webapp
npm run dev
# เปิดเบราว์เซอร์ไปที่ http://localhost:5173
```

### คำสั่งทดสอบและตรวจสอบคุณภาพโค้ด
```powershell
npm test          # รันชุดทดสอบความถูกต้องของข้อมูล (5/5 suites)
npm run lint      # ตรวจสอบโค้ดด้วย oxlint (0 errors, 0 warnings)
npm run build     # บิลด์โค้ดสำหรับ Production (tsc + vite)
npm run preview   # พรีวิว Production build
```
